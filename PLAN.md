# Project Plan

## Keystroke Recognition Using Machine Learning

### 1. Project Objective

To develop a machine learning system that recognizes users based on their unique typing patterns using keystroke data.

### 2. Development Plan

```text
        ↓

        ↓

        ↓

        ↓

```

### 3. Technologies

* Python
* Pandas
* NumPy
* Scikit-learn
* Tkinter
* Matplotlib
* Random Forest

### 4. Main Modules

1. **Data Collection** – Collect typing behaviour.
2. **Feature Extraction** – Calculate dwell time and flight time.
3. **Data Processing** – Prepare the dataset.
4. **Model Training** – Train the Random Forest model.
5. **User Recognition** – Predict the user from typing patterns.
6. **GUI** – Display the system and prediction results.
7. **Testing** – Verify system performance.
8. **Deployment** – Prepare the application for use.

### 5. Project Commands

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

### 6. Expected Outcome

The completed system should collect keystroke data, analyze typing behaviour, and identify the user using the trained machine learning model.
